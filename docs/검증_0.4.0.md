# 방이 생활지도 0.4.0 검증 결과

검증일: 2026-10-11, 기존 NCP 비공개 스테이징 `https://localhost:8443`.

## 데이터와 실시간 연동

전체 165곳: 따릉이 58곳, 화장실 74곳, 주차장 33곳. 주차장은 기존 1곳에서 32곳을 추가했다. 서울시 도시데이터의 올림픽공원과 잠실 관광특구 자료, 공영주차장 안내 자료를 시설 코드로 합쳤다. 좌표가 없는 시설은 추정해 넣지 않았다. 전체 시설을 빠짐없이 수록한 지도는 아니다.

잠실역, 잠실나루역, 신천유수지 3곳은 서울시 시영주차장 API와 연결했다. 총 주차면에서 주차 중 차량 수를 빼서 잔여면을 표시한다. 서버가 5분마다 확인하고, 서울시 제공 시각이 10분 이상 지나면 현재 수량으로 표시하지 않는다. 미제공 시설 30곳은 0면으로 오인되지 않게 구분했다. 수량은 변동하며 입차를 보장하지 않는다. `evidence/parking-verification.json`에 실제 수량과 제공 시각을 기록했다.

시설 메타데이터를 다시 생성해 정규화 결과와 V5/V7의 해시가 변하지 않는 것을 확인했다. 서울시 키는 이전에 승인한 HTTP 공식 API에서 서버 수집에만 사용한다. 공개 API 응답과 소스/웹 산출물에서 실제 키가 노출되지 않았음을 검사했다.

## HTTPS

사용자 승인으로 Mac 사용자 키체인에 SSL용 `Bangi Localhost CA`를 등록하고 서버 인증서를 교체했다. CA의 이름 제약은 localhost DNS 범위만 허용하고 모든 IP 이름을 제외한다. CA 개인키는 서버에 전송하지 않았다. 다른 도메인과 IP를 사용한 검증용 인증서는 이름 제약 오류로 거부되는 것을 확인했다. 이전 leaf 인증서의 사용자 신뢰는 제거했다.

서버 TLS 검증 성공, leaf CN/SAN localhost, issuer Bangi Localhost CA. leaf 만료는 2027-01-09 12:01:18 UTC다. Chrome 재시작 후 **“이 연결은 안전합니다.”**를 실제 보안 메뉴에서 확인했다. 브라우저 경고를 우회하거나 TLS 검증을 끄지 않았다. 이 Mac의 localhost 터널용 설정이며 외부 공개용 공인 TLS를 뜻하지 않는다.

## 테스트와 배포

- Java 테스트 14건 통과: 기존 배포/수량/사진 8건, 주차 파싱 6건. 실제 API의 `192.0` 숫자 형식, 만차/빈 주차장, 결측/음수/소수/면수 초과, 미제공 플래그, 오래된 시각 보존, 미래/잘못된 날짜를 검증했다.
- TypeScript 검사와 linux/amd64 API/웹 이미지 빌드 성공. Cesium은 지연 로딩하며 큰 번들 경고는 남아 있다.
- 로컬 및 NCP HTTPS API 테스트 7건(상위 테스트 포함) 통과. 공간 검색, 주차 출처와 수량, 인증, Origin/CSRF, 비공개 제보/사진, 재시도 중복 방지, 동시 수정 충돌, 답변과 로그아웃을 확인했다.
- 실제 Chrome에서 주차장 33곳, 실시간 연동 필터 3곳, 잠실역 상세의 총면수/주차 중/잔여면/서울시 제공 시각을 확인했다.
- 390×844 뷰포트에서 모바일 목록/지도 전환과 상세 진입을 확인했다. Chrome 확대율로 CSS 너비는 433px였고 scrollWidth도 433px로 가로 넘침이 없었다. 체크박스는 15px로 표시됐다. 검증 후 크기를 원복했다. 최종 브라우저 오류/경고 로그는 없었다.
- 배포 전 133곳 DB와 배포 후 165곳 DB를 각각 로컬 비공개 파일에 백업했다. 별도 임시 DB에 복원하여 시설 좌표와 메타데이터, 제보/사진의 해시가 원본과 일치했다. 마지막 복원에는 장소 165곳, 제보 5건, 기존 사용자 1명이 포함된다.

기존 NCP 무료 Micro와 공인 IP를 유지했고 새 유료 자원은 생성하지 않았다. V6/V7은 추가 방식 마이그레이션이다. 기존 계정과 제보, 이전 이미지 참조 및 TLS 파일을 롤백용으로 보존했다.

배포 직후 관측: API 170.3MiB, DB 83.17MiB, 웹 4.86MiB. 호스트 가용 메모리 362MiB, 디스크 여유 2.2GiB. 세 컨테이너 OOMKilled=false, 재시작 0. 단기 기능 검증이며 장시간 부하 시험이나 고가용성 보장은 아니다.
