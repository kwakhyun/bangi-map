# 방이2동 실사 데이터 누락과 시점 점검

> 조사일 기준의 데이터/이용 조건 및 검증 기록이다. 2026-10-29 NCP 운영을 종료했으며 현재 서비스 제공이나 외부 API 키의 유효성을 보장하지 않는다. 재사용 시 제공처의 최신 조건을 확인한다. [운영 종료 기록](운영_종료.md)을 참고한다.

확인일: 2026-10-12. 대상: 당시 배포 중이던 방이2동 지도, 브이월드 LoD4 공식 메타데이터, 서울시 S-Map과 데이터 제공 FAQ(2026.04.), Overture 공식 릴리스 목록.

## 결론

- 브이월드 공식 LoD4 구축표는 **서울 전역, 2024년, 605㎢, 구축기관 지자체**로 안내한다. 방이2동은 이 지역 범위에 들어간다. 이것은 지역 단위 구축 범위이며 모든 건물이 빠짐없이 존재한다는 검수 결과가 아니다.
- **건물별 정확한 촬영일과 실사 누락 수는 확정하지 못했다.** 공개 메타데이터에서 모델별 식별자, 제공 범위, 촬영일 목록을 확보하지 못해 현재 건물 도형과 일대일 대조할 수 없다. `missingCount`는 0이 아니라 `null`, 각 건물의 실사 상태는 `UNVERIFIED`로 기록했다.
- S-Map에서 **2025년 3D 건물과 배경지도**를 선택한 방이2동 주민센터 주변의 외벽과 지붕을 확인했다. 확인한 무료 조회 자료 중 브이월드 지역 구축표의 2024년보다 최신 연도를 제공한다. 2025라는 레이어 연도만으로 각 건물의 촬영 연월일이나 모든 건물 갱신을 확정할 수는 없다.
- S-Map 3D 원본은 공개제한 공간정보로, 제공 신청과 심사 없이 우리 서버에 복사할 수 있는 다운로드 자료가 아니다. **새 원본 모델을 확보하거나 교체하지 않았다.** 무료 외부 비교 링크와 확인된 메타데이터를 서비스에 보완했다.

## 전체 보유 건물 점검

단위는 방이2동 경계 안에 대표점이 있는 Overture 건물 도형이다. 실제 현존 건물 전수나 브이월드의 실사 모델 수와 동일하지 않다.

| 확인 항목 | 결과 | 의미 |
|---|---:|---|
| 도형 수 / 고유 ID | 1,484 / 1,484 | ID 중복 없음 |
| 유효 도형 / 원본 일치 | 1,484 / 1,484 | 가져오는 과정에서 도형 손실 없음 |
| OSM 원천 | 974 | 원천 속성 update_time은 2025-02-12~2026-08-29 |
| East Asian Buildings 원천 | 510 | 원천 속성 update_time은 2024-11-01 |
| 원본 높이 / 층수 추정 / 높이 미확인 | 646 / 10 / 828 | 실사 누락 판정과 별개 |
| 외벽 및 지붕 속성 8종 | 각 0 | 도형 자료만으로 실제 외관 복원 불가 |
| 실사 일대일 대조 완료 | 미완료 | 모델 목록과 촬영일 자료 미확보 |
| 실사 누락 수 / 완전 제공 수 | 미확인 / 미확인 | 0 또는 1,484로 추정하지 않음 |

`source_update_time`은 지도 원천의 수정 시각이지 사진 촬영일이 아니다. Overture의 2026-09-23.1은 배포일이다. 공식 릴리스 목록에서 현재 적용본보다 새로운 배포본은 확인되지 않았다.

전체 1,484행의 점검 목록은 `evidence/realistic3d/building-coverage-audit.csv`, 집계와 출처는 `coverage-audit.json`에 저장했다. 건물별 실사 모델 ID와 촬영일 칸은 빈 값으로 유지한다. 서비스에서도 같은 파일을 내려받을 수 있다.

## 시점의 근거와 불일치

### 브이월드

[LoD4 공식 메타데이터](https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?svcCde=DT&dsId=DAT_0000000000000125)의 상세 버튼 아래 이미지 표에서 서울 전역의 2024년 구축을 확인했다. 화면 증거: `evidence/realistic3d/vworld-seoul-build-year.png`.

같은 페이지의 ‘최근 서비스 갱신시기’는 2022-08-16이다. 2024년 구축표와 불일치하는 오래된 필드이므로, 이를 최신 갱신일이나 방이동 촬영일로 사용하지 않는다. 원본 포맷은 3ds/jpg, 서비스 포맷은 xdo/jpg로 안내하며, 원본 확보는 구축기관 문의로 되어 있다. 개별 파일의 갱신 헤더나 로딩 시각도 촬영일의 증거가 될 수 없다.

### S-Map

[S-Map](https://smap.seoul.go.kr/)에서 방이2동 주민센터 검색 후 2025년 3D 건물과 배경지도를 직접 확인했다. 화면 증거: `evidence/realistic3d/smap-bangi2-2025.png`.

[서울시 2025-01-06 발표](https://mediahub.seoul.go.kr/archives/2013136)는 당시 제공한 서울 전역 데이터의 촬영 기간을 **2024년 3~6월**로 설명한다. 이 발표를 2025년 선택 레이어의 촬영일 또는 현재 브이월드의 특정 건물 촬영일로 옮겨 쓰지 않는다. 2025년 레이어의 정확한 촬영 기간은 확보한 자료에서 확인하지 못했다.

## 무료 보완과 제공 조건

| 자료 | 확보 또는 확인 | 적용 |
|---|---|---|
| 브이월드 공식 SDK 실사 지도 | 기존 무료 개발키 사용 | 기존 연결 유지, 구축연도와 미확인 범위 안내 추가 |
| S-Map 2025년 지도 | 무료 조회, 별도 키 없이 방이동 화면 확인 | 서비스에 공식 공유 링크 추가, 외부 사이트임을 표시 |
| S-Map 실외 건물 원본 | 아직 확보 못 함 | 임의 복사 및 재배포 없음 |
| Overture 2026-09-23.1 | 현재 적용본, 신규 릴리스 미확인 | 원본 도형 유지, 전체 점검 목록 추가 |
| 국토정보플랫폼 영상 | 공식 안내상 위성정사영상 등 제공 | 지붕 상공 영상은 외벽 3D 모델 대체 자료가 아니며, 이번에 방이동 최신 영상 파일을 확보하지 않음 |

[서울시 오픈랩](https://openlab.eseoul.go.kr/) Q&A 상단 ‘S-Map 데이터 제공 관련 FAQ 안내’의 **2026.04. PDF**를 내려받아 2~7쪽을 확인했다. 내려받은 원문은 로컬에만 보관하며 공개 저장소에는 포함하지 않는다. 원문은 해당 공식 사이트에서 확인한다.

- 일반 안내: S-Map 3D는 공개제한 공간정보로 취급하며 사용목적, 타당성, 관리대책 검토가 필요하다.
- 민간 사업자: 사전 컨설팅, 보안심사, 적합 판정 후 사용 신청과 수령 절차를 안내한다.
- 학술 연구: 별도 사용신청서, 보안계획서와 서약서, 기관장이 확인한 연구계획서 등이 필요하다. 현재 프로젝트가 학술 연구 자격에 해당한다고 가정하지 않았다.
- 실외 건물 제공 형식은 3DS, OBJ, GcityGML(2.0)이다. 갱신주기는 매년으로 안내하나 실제 방이2동 제공본 연도는 신청 전 확인이 필요하다.
- 확인 자료에 확정 요금은 없다. **무료 원본 제공이나 심사 비용 0원을 보장할 수 없다.** 새로운 API 키만으로 원본 이용 조건이 해결되는 것도 아니다.

원본 제공 담당: 서울시 공간정보과 공간정보운영팀 02-2133-2852. 문의나 신청은 아직 발송하지 않았다.

## 남은 확인에 필요한 자료

1. 방이2동 경계에 해당하는 브이월드/서울시 모델 목록과 공간 범위, 건물 ID 대응표.
2. 건물별 또는 촬영 도엽별 촬영일, 구축연도, 최근 갱신일, 결측 사유.
3. 최신 방이2동 실외 모델의 원본 제공 가능 여부와 외벽 텍스처 포함 여부.
4. NCP의 비공개 개발 서버와 브라우저 스트리밍에 허용되는 이용 범위, 변환/경량화 및 재배포 조건, 비용.

제공기관 자료가 확보되면 도형과 모델의 공간 교차율 및 다대일 대응을 검사하고, 신축/철거/분할/합동 모델을 구분한 뒤 실제 누락 목록을 만들 수 있다. 현재 스크린샷의 빈 공간이나 기본 지도의 높이 미확인 828개를 실사 누락으로 간주하지 않는다.

## 재현

```sh
.tools/gis-venv/bin/python scripts/audit-photoreal-coverage.py
.tools/gis-venv/bin/python tests/gis-data.py
```

실행 가능한 분석 노트북: `evidence/realistic3d/coverage-audit.ipynb`. 코드 검증은 원본 일치, ID와 도형 품질을 확인한다. 공식 표의 연도는 원문 화면을 읽어 기록한 값이며 자동화된 실사 전수 검수 결과가 아니다.
