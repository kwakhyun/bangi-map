# 방이2동 3D 생활지도

> 2026-10-29 NCP 운영을 종료했다. 아래 기능 설명은 보존된 소스의 구현 범위이며 현재 서비스 제공을 뜻하지 않는다. [운영 종료 기록](운영_종료.md)을 참고한다.

2026-10-11 개편. 방이2동의 실제 공간을 둘러보며 주변 생활시설을 찾는 동네 GIS 서비스다. 기본 탐색 범위는 행정동 방이2동이며, 법정동 방이동 전체와 구분한다.

## 핵심 이용 흐름

1. 실제 방이2동 경계와 건물, 도로, 공원이 보이는 3D 지도에서 시작한다.
2. 시설 종류를 선택하거나 이름으로 검색한다. 건물 탭에서는 원본 이름이 있는 건물과 높이 정보를 탐색한다.
3. 지도나 목록에서 건물을 선택해 높이와 층수, 출처를 확인한다. ‘이 건물에서 가까운 시설’로 거리순 탐색을 이어간다.
4. 주차, 따릉이, 화장실 상세에서 이용 정보와 데이터 기준 시각을 확인하고 길찾기, 저장, 정보 제보를 사용한다.
5. 기본 범위 안에 원하는 시설이나 실시간 정보가 없으면 ‘주변 포함’을 켠다. 경계 밖 시설은 주변 표시로 구분한다.

## 화면과 조작

여백과 절제된 색상, 작은 단계의 정보 공개를 사용한다. 검색과 결과 목록은 왼쪽, 선택한 대상의 행동과 상세 정보는 오른쪽에 배치한다. 모바일에서는 지도를 유지하면서 하단 목록과 상세 화면을 펼친다. 3D 시점/상부 시점, 확대, 북쪽 정렬, 전체 범위 복귀, 레이어 설정, 직선거리 측정을 제공한다.

특정 기업의 화면이나 자산을 복제하지 않고, 토스와 애플에서 참고한 가독성, 정보 위계, 일관된 조작 원칙을 현재 서비스에 적용한다.

## 데이터 신뢰 기준

실제 원본 도형을 사용하고, 높이 646개는 원본 속성, 10개는 층수 추정, 828개는 미확인으로 구분한다. 시설은 PostGIS 경계 포함 판정을 통과한 30곳을 기본 제공한다. 주변까지 확장하면 165곳이다. 방이2동 내 주차장 15곳의 실시간 잔여면은 미제공이며, 연결된 주변 주차장 3곳만 수량을 표시한다.

사진 기반 정밀 복제, 건물 실내, 실측 지형, 일조권 분석, 보행 경로 계산을 제공한다고 표현하지 않는다. 거리 측정과 정렬은 지면 기준 직선거리다. 기존 길찾기 버튼은 외부 지도 서비스로 연결한다.

## 운영 종료와 보존 범위

기존 NCP Micro 서버, 디스크, 공인 IP와 전용 네트워크는 삭제했고 SSH 접속 환경과 자동 배포도 종료했다. 코드와 공개 데이터, 당시 검증 기록은 보존한다. 브라우저 3D 렌더링, Java API, 제보/운영자 처리와 수집기 구현은 남아 있으나 현재 실행 중인 배포 서비스는 없다. 로컬 실행과 새 운영 환경의 조건은 [실행과 재구축 안내](운영.md)에 있다.

운영을 재개하고 공개 출시하려면 도메인과 공인 인증서, 자동 백업과 장애 알림, 실제 모바일 성능과 접근성 점검, 제보 보존 정책을 추가로 정리해야 한다. 브이월드 사진 기반 3D 연동은 0.6.0에서 구현했으며, 건물별 촬영일/누락 검증과 데이터 원본 정기 갱신은 남은 과제다.
