# 방이2동 3D 생활지도 0.5.0 검증 결과

> 과거 구현/검증 기록이다. 2026-10-29 NCP 서버와 접속 환경을 제거하고 자동 배포를 중단했다. 아래 주소, 서버 상태, 복구 명령과 검증 결과는 작성 당시 기준이며 현재 실행 환경을 뜻하지 않는다. [운영 종료 기록](운영_종료.md)을 참고한다.

2026-10-11 기존 NCP Micro 스테이징에 배포했다. 당시 접속 주소는 `https://localhost:8443`이었으며 작성자 Mac의 SSH 터널을 사용했다. 0.4.0의 검증 기록은 `검증_0.4.0.md`에 보존했다.

## 공간 데이터와 표시

- SGIS 원자료를 가공한 vuski/admdongkor `ver20260701`의 실제 방이2동 행정 경계. 행정동 코드 1171056200, SGIS 코드 11240580.
- Overture 2026-09-23.1 건물 1,484개. 원본 도형과 좌표가 모두 일치하고, 유효한 도형의 내부 대표점이 방이2동에 포함되는 것을 확인했다.
- 원본 높이 646개, 층수 × 3.3m 추정 10개, 높이와 층수가 없는 828개. 마지막 그룹은 평면 외곽으로만 표시한다. 원본 높이는 실측 인증값이 아니다.
- 같은 배포본의 실제 도로 404개, 공원 6곳과 방이중학교 부지 1곳을 표시한다. 공원/학교는 행정동 경계로 잘랐다.
- PostGIS ST_Covers 기준으로 시설 30곳(따릉이 3, 주차장 15, 화장실 12)이 경계 안에 있다. 주변 포함에서는 기존 165곳을 유지한다.
- 방이2동 내 주차장 15곳은 잔여면 미제공이다. 잠실역, 잠실나루역, 신천유수지 3곳은 경계 밖으로 명시하고 기존 실시간 수집을 유지한다.

`scripts/import-bangi2.py`, `scripts/enrich-bangi2-context.py`와 `tests/gis-data.py`로 원본 검증과 가공을 재현한다. 실제 출처, 원본 해시, 라이선스와 처리 방식은 `data/bangi2/`에 기록했다. 가공 공간 파일과 출처를 웹에서 다운로드할 수 있다.

## UI와 기능 확인

실제 Chrome의 로컬 개발 화면과 NCP HTTPS 배포 화면에서 확인했다. 시설/건물 목록과 3D 지도, 선택 강조 및 확대, 건물 상세의 원본 높이/층수/출처, 주변 시설 연결, 상부 시점과 3D 시점 전환, 전체 범위 복귀, 레이어 토글, 높이별 색상, 직선거리 측정이 동작한다. 거리 측정은 두 지점을 선택하여 392m 결과를 확인했다. 그림자는 기준면에 투사하는 참고 표현이다.

모바일 하단 목록 펼치기, 건물 상세 진입 및 닫기, 지도 유지와 전체 범위 복귀를 확인했다. 390×844 브라우저 뷰포트 설정에서 기존 Chrome 확대율 때문에 실제 CSS 너비는 433px였으며 문서 너비도 433px로 가로 넘침이 없었다. 검사 후 뷰포트를 원복했다. 실제 휴대폰 기기나 저사양 GPU의 성능 검증을 대신하지 않는다.

최종 NCP 탭의 브라우저 오류와 경고 로그는 없었다. 기존 공공데이터 수집과 제보/운영자 기능은 API 통합 검사로 검증했다. CI용 브라우저 회귀 테스트도 새 화면에 맞게 갱신했으나 이 작업에서 별도 Playwright 실행은 하지 않았으며, UI 검증은 실제 Chrome 도구로 수행했다.

## 빌드, 데이터베이스, HTTPS

- TypeScript 검사와 React/Vite 프로덕션 빌드 성공. Java 단위 테스트 14건 성공. linux/amd64 웹/API 이미지 0.5.0 빌드 성공.
- 로컬 및 NCP API 통합 테스트 8건(상위 테스트 포함) 성공. 경계 안/밖 분리, 잘못된 scope 거부, 세 높이 유형의 건물 조회, 시설 출처와 수량, 인증/Origin/CSRF, 비공개 접수, 중복 방지, 수정 충돌 및 답변을 포함한다.
- V8 마이그레이션 적용 성공. 유효한 건물 도형 1,484개. API 역할은 새 건물/경계 테이블을 읽을 수 있고 건물 INSERT는 거부된다.
- NCP가 제공한 정적 공간 파일의 SHA-256이 로컬 검증본과 일치한다. 없는 공간 파일은 HTML 대신 404를 반환한다.
- 기존 Bangi Localhost CA로 HTTPS 검증 성공. 인증서 localhost, 만료 2027-01-09 12:01:18 UTC. TLS 검증이나 브라우저 경고를 우회하지 않았다.
- 배포 전 DB 백업과 복원 검증 완료. 배포 후에도 시설 165곳, 건물 1,484개, 사용자 1명과 검증용 제보를 포함한 DB를 임시 DB로 복원했다. 건물 도형/속성, 경계, 시설과 제보의 해시가 일치한다.

공간 JSON은 1,161,756바이트, gzip 170,440바이트다. Cesium은 지연 로딩되며 gzip 약 1.1MB이고 번들 크기 경고는 남아 있다.

## 서버와 복구

기존 NCP 1 vCPU/1GB Micro, 기존 DB와 공인 IP를 재사용했다. 새로운 유료 자원은 생성하지 않았다. 사용자 승인으로 SSH 접근을 당시 관리자 주소 한 곳(/32)의 TCP 22로 제한했다. 실제 주소는 비공개 운영 설정에서 관리한다. 웹 포트는 여전히 서버 localhost에만 바인딩된다. 접속 네트워크가 달라지면 터널을 사용하려면 IP 규칙을 갱신해야 한다.

최종 관측: API 169.9MiB, DB 109.7MiB, 웹 3.914MiB. 호스트 가용 메모리 349MiB, 디스크 여유 2.1GiB. 컨테이너 3개 모두 OOMKilled=false, 재시작 0. 단기 기능 검증이며 장기간 부하나 고가용성을 보장하지 않는다.

이전 API/웹 이미지 참조는 서버 `/opt/fieldtwin/rollback-bangi-20261011-223637/compose.env`에 보관했다. V8은 추가 방식으로 0.4.0 롤백 시 DB 삭제가 필요 없다. 이번 이미지 전송용 압축 파일만 서버에서 제거했다. 실행 이미지와 이전 이미지, DB, 백업은 보존했다.
